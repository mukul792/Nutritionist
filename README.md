# 🍎 Health & Calorie Estimator App

A Streamlit-based application that uses **Google Gemini Vision (gemini-pro-vision)** to analyze food images and estimate total calories.  
The app combines **image understanding** with **nutrition-focused prompting** to identify food items and generate an itemized calorie breakdown.

---

## 🚀 Features

- Upload food images (JPG, PNG, JPEG)  
- View the uploaded image directly in the app  
- AI identifies all visible food items  
- Provides **item-wise calorie breakdown**  
- Calculates **total estimated calories**  
- Uses **Gemini Vision** for multimodal image + text understanding  
- Clean and interactive **Streamlit UI**

---

## 🧠 How the App Works

- Accepts a food image uploaded by the user  
- Converts the image into the format required by Gemini  
- Sends both the prompt and image to the model  
- Gemini analyzes the food items and returns:
  - Each item detected  
  - Estimated calories per item  
  - Total calorie intake
